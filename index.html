📘 1. NAI V4.5 基本生成パラメータ攻略

• Prompt Guidance (CPG / ガイダンス度合い): 推奨 5.0 〜 7.0
AIがプロンプト命令にどれだけ従うかの数値。低め(3〜4)だと柔らかく幻想的でAIの自主的な描き込みが増えます。高すぎ(8〜10+)にするとコントラストが過剰になり「揚げ物感」と呼ばれる画質劣化が発生します。
• Prompt Guidance Rescale: 推奨 0.0 〜 0.5
CPGを高く設定した際、画像の色飽和や破綻を抑え込む「セーフティブレーキ」機能です。画面のコントラストがキツいと感じたらRescaleを上げるかCPGを下げましょう。
• Steps (生成ステップ数): 28 (標準)
描き込み精緻化の回数。28で最もバランス良く仕上がります。高すぎると色が飽和するため注意が必要です。

📊 3. AITAG実生成データで観測された傾向

【クオリティタグの観測頻度】
AITAGの各タグは「そのタグを1回以上含む画像数」を分子にして表示します。高頻度は実生成で多く観測されたことを示しますが、効果の高さや因果関係を保証しません。
【ライティングタグの利用例】
volumetric lighting、rim lighting、dramatic lightingなどは実生成プロンプトで観測されます。使用率は採用候補を探す指標であり、画質向上を直接証明するものではありません。
【根拠を分離】
AITAGはNovelAI V4.5で入力されたプロンプト、Danbooru / Safebooru / Yande.reは画像アノテーションです。Danbooru系で頻出でもNovelAIでの効果は保証されないため、件数を別々に表示します。

⚡ 4. Numerical Emphasis（Official）

• 数値強調: 数値::tag ::
1.2::cel shading :: や 0.8::soft shading :: のように、終端の :: までを重み付けします。{tag} / [tag] による強化・弱化も利用できます。
• Negative Numerical Emphasis（V4.5以降）
-1::text :: のように対象概念を狙って弱める用途です。Undesired Content全体の代替ではなく、結果を比較しながら利用してください。

🛡️ 5. ネガティブプロンプトの設計原則

公式V4.5 Full UC（Light / Heavy / Human Focus / Furry Focus / None）と、本辞典独自のCustom UCを分けて表示します。観測辞典ではQuality、Anatomy、Hands、Eyes、Composition、Text / Logo、Artifacts、Style、Otherに分類しています。

🖼️ 6. Vibe Transfer & References (参照イラスト) 活用のコツ

Vibe Transferは参照画像から雰囲気を取り込む機能で、Reference StrengthとInformation Extractedを調整します。公式はInformation Extractedの既定値を起点に実験するよう案内しており、固定の最適値は示していません。

🧪 7. Precise Referenceとの機能分離

• Precise Reference（Official）
V4.5専用の別機能で、StrengthとFidelityを持ちます。公式は数値ラベルから負値を入力できると案内していますが、固定の推奨負値は示していません。
• 互換性
Vibe TransferとPrecise Referenceは現在同時利用できません。Vibe TransferのInformation ExtractedとPrecise ReferenceのFidelityを混同しないでください。
• Numerical Negative Emphasis
-1::text :: はプロンプト内の概念へ作用する別機能です。画像参照の負値入力とは分けて扱います。
